# ルーチン

ルーチンは、終わらない側のタスク。毎日の運動、週3回の記録、月曜の週次レビュー — 曜日が来れば戻ってくるもので、START も GOAL も依存関係も持たない。

ストーリーが「終わりに向かって進むもの」なら、ルーチンは「戻ってくるもの」。分けてあるのは見た目の都合ではなく、**DONE の意味が違う**ため。

- タスクの DONE は終わり。かつ、後ろのタスクを解くもの。
- ルーチンの DONE は「今日の分は済んだ」。明日にはまた空になる。

同じグラフに入れると、毎晩リセットされるノードが下流を BLOCKED に突き落とし、Current Frontier は永久に埋まったままになる。だから別の場所にある。

## 開く

ドロワーの上の方、Workspace の下にある **Routines**。URL は `/routines`。

## 作る

画面右上の **New routine**。

| 項目 | 必須 | 意味 |
| --- | --- | --- |
| Title | ○ | ルーチンの名前（200文字まで） |
| Description | | 補足（5000文字まで） |
| Days | ○ | 戻ってくる曜日。最低1日 |

曜日は7つのトグルで選ぶ。**Every day / Weekdays / Weekends** のショートカットは別モードではなく、同じ7つのトグルをまとめて動かすだけ — 「平日だけど水曜は除く」は、押したあと水曜を1回外せばいい。

全部の曜日を外すことはできない。どの曜日にも来ないルーチンはルーチンではないので、最後の1日は押しても消えない。

## チェックする

今日の分は、行の左のチェックボックス。**押した瞬間に入る** — サーバーの返事は待たない。失敗したときだけ元に戻り、理由がトーストで出る。

今日が対象の曜日でない行には、チェックボックスそのものが出ない（押しても断られるボタンを置くよりは、置かないほうがいい）。

画面は3つに分かれる:

- **Today** — 今日が対象の曜日で、動いているもの
- **Other days** — 動いてはいるが、今日ではないもの
- **Paused** — 一時停止中のもの

上の行に「あと何件」が出る。全部済んでいれば **All done for today.**

## 記録

チェックは**列の書き換えではなく行の追加**として保存される。「今日やったか」は今日の行があるかどうか、それだけ。だから真夜中に何かがリセットされることはない — 明日にはまだ行がない、というだけ。

その結果として2つ付いてくる:

- **連続記録** — 「7 in a row」。対象曜日だけを数えるので、月水金のルーチンにとって火曜は「休んだ日」ではない。
- **直近の点** — 対象だった日を古い順に7つ。埋まっていれば済んだ日、空なら抜けた日。

**今日はまだ数えない。** 対象の曜日で、まだチェックしていないだけの日は「抜けた日」ではないので、朝の時点で連続記録が0に落ちることはない。

読む範囲は直近180日。それより前は数えない。

## 止める・消す

行の **⋮** から:

- **Pause** / **Resume** — 止めても記録は残る。やらなくなったルーチンほど、いつまでやっていたかが残っている価値がある
- **Delete** — 記録ごと消える。取り消せない

## 「今日」はどっちの今日か

チェックボックスが扱う日付は、**ブラウザのある場所の今日**。サーバーの UTC ではない。

タスクの期日バッジは UTC で判定していて、東京では数時間ずれることがある。バッジなら少し早いだけで済むが、チェックボックスは違う — UTC で判定すると、東京では朝9時に今日の分のチェックが一斉に消えることになる。

ページを開いたまま日付が変わった場合は、タブに戻ってきた時点で読み直す。

## API

ブラウザ以外からも触れる。エンドポイントの一覧は `cli/README.md`。

```
GET    /api/v1/routines?workspaceId=…&date=YYYY-MM-DD
POST   /api/v1/routines
PATCH  /api/v1/routines/{id}
DELETE /api/v1/routines/{id}
PUT    /api/v1/routines/{id}/completion   { "date": "…", "done": true }
```

`date` はその人の「今日」。省略すると UTC の今日で答える。
