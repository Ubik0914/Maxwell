# 3つのビュー

同じストーリーを3通りに見られる。タブは広い画面ではヘッダーの下、スマホでは画面の下端にある。どれも URL を持っているので、そのまま人に送れる。

- **Graph** — どう組み合わさっているか
- **List** — 次に何をするか、何が邪魔をしているか
- **Board** — 手を動かしながら状態を移す

## 共通の絞り込み

List と Board の上には同じフィルタバーがある。

- **検索** — タイトルと説明にかかる。
- **状態のチップ** — All / Ready / In progress / Done / Cancelled / Blocked。それぞれ件数付き。

スマホでは**左右にスワイプ**するとフィルタが1つずつ動く。端で止まり、反対の端には回り込まない。

## List

列は **Status / Task / Waiting on / Priority / Due / Assignee**。狭い画面では右側の列から順に落ちる。

既定の並びは **urgency（緊急度）順**:

1. In progress — 手をつけたまま放ってあるものがいちばん悪い
2. Ready
3. Done
4. Cancelled
5. Blocked — 今どうにもできないものは最後

見出しを押すと、その列で並び替わる（もう一度押すと逆順）。**Waiting on** と **Assignee** は並び替えできない — 前者は件数で並べても意味がなく、後者はまだ ID のままなので、名前順にしようがないため。

左上のボタンで**手動並び替え**に切り替えると、行の左に掴む場所が出てドラッグで好きな順に置ける。手動の順序はストーリーに保存される。**Back to urgency order** で戻る。

## Board

列は **Ready / In progress / Done / Cancelled / Blocked** の5つ。カードをドラッグして落とすと状態が変わる。

BLOCKED 列だけは入れられない（[ステータス](/docs/status)を参照）。落とせない移動はドロップ時に断られ、理由がトーストで出る。

カードの左の掴む部分は、ドラッグのほか**矢印キー**でも動かせる。

## Graph

グラフの操作は[グラフを組む](/docs/graph)にまとめてある。

## 全ストーリーをまとめて見る

ドロワーの Stories の先頭にある **All stories** から、ワークスペースの全ストーリーを1画面で見られる。3つのビューはそのまま使える — 今 Board にいるなら All stories も Board で開く。

- `/stories/all` — 全ストーリーのグラフ。ストーリーごとに横のレーンに分かれて縦に積まれる。レーンの名前を押すとそのストーリーへ入る。
- `/stories/all/list` — 全タスクを1つの表に。**Story** 列がどのストーリーのものかを言う。
- `/stories/all/board` — 全タスクを1つのボードに。カードの上にストーリー名が出る。

タスクを開いて、タイトル・説明・ステータスを変えるところまでは個別のストーリーと同じ。できないことが2つある:

- **グラフ上でのノードの移動と接続** — レーンの座標はこの画面が計算したもので、ストーリー自身が持っている座標ではない。ここで動かして保存すると、そのストーリーの中では誰も置いていない場所に飛ぶ。依存を引くのも同じ理由で不可 — 辺は1つのストーリーの中のものなので、隣り合って見える2つが同じストーリーとは限らない。
- **手動並び替え** — 手動の順序はストーリー1本の中の並び。2本を交互に混ぜた順序は、どちらのストーリーも頼んでいない。List の **Manual** ボタンはこの画面では出ない。
