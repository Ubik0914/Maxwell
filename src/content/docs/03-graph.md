# グラフを組む

グラフはストーリーの本体。**START** と **GOAL** は両端として最初からあり、消せない。その間に置くものが TASK ノード、繋ぐ線が依存関係（エッジ）。

エッジの向きは「先にこちら」。`A → B` は「B を始める前に A が終わっている必要がある」という意味しか持たない。

## タスクを足す 3つの方法

### 1. 線の上に挿す — Insert task

エッジにカーソルを合わせると真ん中に「+」が出る。押すと **Insert task** が開く。

`A → B` は `A → 新しいタスク → B` になる。元の `A → B` は残らない — 割り込ませるのであって、並べるのではない。まだ何も無いストーリーで START → GOAL に挿すのが、最初の1個を置くいちばん短い道。

### 2. あるタスクの後ろに足す — Add next task

ノードにカーソルを合わせると出る「+」から。**Add next task** は `このタスク → 新しいタスク → (合流先)` を作る。合流先はダイアログの中で選ぶ（既定は今そのタスクが繋がっている先）。

こちらは元の線を消さない。同じ2点の間を並走する枝を足せる。

### 3. どこにも繋がないで作る — New task

グラフ左下のツールバーのいちばん左、**New task**。孤立したタスクとしてキャンバスに現れる。あとから線を引いて繋ぐ。

## 依存を引く・外す

- **引く** — ノードの端のハンドルをドラッグして、別のノードのハンドルに落とす。
- **外す** — エッジにカーソルを合わせて **Delete connection**。

引けない線は引けない。**循環は拒否される**（A → B → A のように自分に戻ってくる線を作ろうとした場合）。同じ2点を結ぶ**同じ向きの線を二重に引くこともできない**。断られたときは、何が問題だったかがトーストで出る。

## 並べる

- ノードはドラッグで動かせる。置いた位置はそのまま保存され、次に開いたときも同じところにある。
- ツールバーの **Arrange by dependency** で、依存関係に沿って自動的に並べ直す。

自動整列は「片づけたい」ときのためのもので、手で置いた位置を捨てる。押す前に、その配置に意味があるかどうかだけ考えるとよい。

## キャンバスの操作

ツールバー（左下）にひととおり揃っている。

- **Fit view** — 全体が入るところまで引く
- **Zoom in / Zoom out**
- **Reset view** — 原点・等倍に戻す

右下のミニマップは全体のどこを見ているかを示す。

## 消す

ノードにカーソルを合わせると出る **Delete task**。そのタスクに繋がっていた線も一緒に消える。線が消えれば、その先で待っていたタスクの状態は計算し直される。

## 動く光について

エッジを流れる光は飾りではなく、そのエッジが「通電している」＝上流が満たされていることを示す。止まっている（灰色の）線は、まだ電気が来ていない依存。

動きが多すぎると感じたら **Settings → Motion** で **Reduced** にできる。既定の **System** は端末側の「視差を減らす」設定に従う。
