# CSV インポート（ベータ）

タスクの一覧を CSV で持っている場合、依存関係ごとまとめて取り込める。

## 出し方

ベータ機能なので、既定では**ボタン自体が存在しない**。

**ドロワー → Settings → Beta → Unfinished features** をオンにすると、グラフ左下のツールバー（「+」の隣）に **CSV** が出る。

この設定は localStorage に持っている（Motion の設定と同じ）。1人・1ブラウザの答えなので即座に効き、気が変わっても代償がなく、別のマシンには付いてこない。「未完成のものを見せろ」という設定は、そちら側に倒すのが正しい。

## 形式

```csv
title,depends_on
Design the schema,
Build the API,Design the schema
Build the UI,Design the schema
Ship it,Build the API;Build the UI
```

| 列 | 必須 | 内容 |
| --- | --- | --- |
| `title` | ○ | タスク名 |
| `depends_on` | | 先に終わっている必要があるタスクのタイトル。複数は `;` 区切り |
| `key` | | タイトルが重複するときの識別子 |
| `description` | | 説明 |
| `due_date` | | `YYYY-MM-DD` |
| `priority` | | 1〜4（Low / Medium / High / Urgent） |

最大 500 行。`depends_on` が指せるのは、**同じファイルの中の行**か、**そのストーリーに既にあるタスク**。

## 取り込んだあとの形

タイトルの一覧だけではグラフにならないので、依存を書ける形になっている。

- 何も待たない行は **START から**繋がる
- 誰にも待たれない行は **GOAL へ**繋がる
- ストーリー作成時の START → GOAL の直結は、その両方が引かれた時点で外れる

状態は全部 READY として入れたあと、Status Engine が計算し直す。何がブロックされているかの答えを、取り込む側が持ち込むことはない。

## 失敗したとき

書き込む前に全部検証し、**問題は行番号付きでまとめて出る**。1行直すたびにやり直す必要はない。

書き込みは1トランザクションなので、途中で失敗して半分だけ入ることはない。
