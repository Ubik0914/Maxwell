# インストールと通知

Maxwell はホーム画面に入れられる。入れると、閉じていても「手が空いたタスク」を知らせに来る。

## ホーム画面に追加する

- **iPhone / iPad (Safari)** — 共有ボタン → 「ホーム画面に追加」。iOS では**これが必須**で、タブのままでは通知の許可を出せない。
- **Android (Chrome)** — メニュー → 「アプリをインストール」。
- **デスクトップ (Chrome / Edge)** — アドレスバー右のインストールアイコン。

入れると URL バーのないウィンドウで開き、アイコンが他のアプリと並ぶ。中身は同じサイトなので、ログインもストーリーもそのまま。

## 通知をオンにする

設定 → Notifications のスイッチ。ブラウザの許可ダイアログに答えると、その端末が登録される。

登録は**端末ごと**。スマホとPCの両方で受け取りたければ、両方でオンにする。逆に、1台だけ切りたいときはその端末でオフにすればいい。

スイッチが「Unavailable」と出るときは、そのデプロイに VAPID キーが設定されていない（`README.md` の環境変数を参照）。「Blocked」はブラウザのサイト設定で拒否した状態で、これを戻せるのはブラウザの設定だけ。

## 何が届くか

2つだけ。

- **待っていた作業が空いたとき** — 前のタスクが DONE になって、依存していたタスクが READY に変わった瞬間。
- **ストーリーが完成したとき** — 全部のタスクが片付いて COMPLETED になった瞬間。

これは好みの設定ではなく、グラフの中で「知らせる価値のある瞬間」がこの2つしかないから。IN_PROGRESS への移動は自分がやったことだし、BLOCKED への差し戻しは次に開いたときで間に合う。

通知は**自分の操作がきっかけのものが自分の端末に**届く。CLI や MCP のエージェントがタスクを DONE にしたときも、動いているのはあなたのトークンなので、あなたの端末に届く——**これが一番効く使い方**で、エージェントがグラフを進めている間、次に何が空いたかを見に行かなくてよくなる。

同じストーリーの通知はひとつにまとまる。エージェントが5つ続けて片付けても、スワイプするのは1回。

Maxwell を開いて見ている最中は、通知は出ずに画面内のトーストになる。目の前で起きたことを端末に鳴らし直しても仕方がないため。

## オフラインのとき

ストーリーの画面は必ずネットワークから取ってくる。キャッシュしたグラフは、誰かがタスクを1つ動かした瞬間に嘘になるので、古い絵を見せるより「オフライン」と言う方を選んでいる。
