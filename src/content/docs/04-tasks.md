# タスク

グラフのノードを押すとタスクのパネルが開く。広い画面では横に並び、スマホでは下から出る。

## パネルにあるもの

いちばん上がタイトル。その下がチップの列で、散文でないものは全部ここに入っている。

| チップ | 内容 |
| --- | --- |
| **Status** | Ready / In progress / Done / Cancelled から選ぶ。Blocked は選べない（[ステータス](/docs/status)を参照） |
| **Priority** | Low / Medium / High / Urgent。未設定のままでもよい |
| **Due** | 期日。カレンダーから選ぶ |
| **Assignee** | 担当者。現状はユーザー ID をそのまま入れる欄になっている |

その下が説明。**Add a description…** を押すと編集に入る。

## 説明は Markdown

見出し・箇条書き・番号付きリスト・引用・表・コード・リンクが使える。生の HTML は書けない（テキストとして表示される）。

チェックリストは表示されるだけでなく、**その場で押して切り替えられる**:

```md
- [x] スキーマを決める
- [ ] API を書く
- [ ] UI を繋ぐ
```

押した結果は説明の本文が1文字書き換わったものとして保存される。タスクの中の細かい手順を、タスクを増やさずに管理したいときのためのもの。

## 画像を貼る

説明の編集中に **Add an image**。PNG / JPEG / GIF / WebP / AVIF、1枚 10MB まで。貼られた画像は Markdown の画像記法として本文に入る。

画像はそのストーリーの持ち物として保管され、ワークスペースを削除すると一緒に消える。

## タスクを消す

グラフのノードにカーソルを合わせて **Delete task**、またはリスト／ボードの行の「⋮」から。そのタスクに繋がっていた依存も一緒に消え、下流の状態は計算し直される。
