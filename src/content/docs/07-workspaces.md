# ワークスペース

ワークスペースはストーリーの入れ物であり、共有の単位でもある。誰が何を見られるかはワークスペース単位で決まる。

## 切り替える

ドロワーの **Workspace** の行（今いるワークスペース名と **Switch**）を押すと、所属しているワークスペースの一覧が出る。

各行に出るのは、名前・自分のロール・中のストーリー数。今いるものには **Current** が付く。押すとそこへ切り替わり、そのワークスペースで最後に触ったストーリーへ入る。

## 作る

一覧の見出しの横の「+」から。まだ1つも持っていないときは、画面の中央に **New Workspace** だけが出る。作るとそのまま新しいワークスペースへ入る。

## ロール

- **OWNER** — 削除も含めて何でもできる
- **EDITOR** — 中身を編集できる
- **VIEWER** — 読める

権限はデータベース側（RLS）で決まっている。画面から消えているボタンは「押しても失敗するボタン」であって、それが権限の実体ではない。

## 削除する

一覧の行の **⋮ → Delete workspace…**。OWNER にしか出ない。

確認は「はい」ではなく、**ワークスペース名を打つ**形になっている。1つのストーリーを消すのとは規模が違い、しかも押した行が思っていた行とは限らないため。ダイアログには消えるストーリーの数も出る。

消えるもの: その中のストーリー全部、そこにあるタスクと依存、貼られた画像、そして他のメンバーのアクセス。**元に戻せない。**
