# ストーリー

ストーリーは、START から GOAL までの1本のグラフ。プロジェクト1つ、機能1つ、あるいは「今月やること」1つがだいたいストーリー1つにあたる。

## 作る

ドロワーの **Stories** の見出しの横にある「+」から作る。ワークスペースにまだ1つもないときは、画面の中央に **New Story** だけが出る。

| 項目 | 必須 | 意味 |
| --- | --- | --- |
| Title | ○ | ドロワーやヘッダーに出る名前（200文字まで） |
| Description | | 何のためのストーリーかを書く。Markdown が使える（5000文字まで） |
| Start State | ○ | START ノードになる。「何が揃っていれば始められるか」 |
| Goal State | ○ | GOAL ノードになる。「どうなったら終わりか」 |

Start と Goal を先に書かせるのは意図的なもの。終わりの条件が言葉にできないうちは、間に何を並べても、それが近づいているのかどうか判定できない。

## 切り替える

ドロワーの Stories が一覧になっている。1行につき出るのは:

- 状態を表す色付きの点とタイトル
- 進捗のレール（Done の割合だけ光る）
- **Done / Ready / Prog / Blocked** のタリー
- 最後に動いた時刻

行の右の **∨** で詳細（About / Goal / Up next）が開く。**⋮** からは Story settings へ行ける。

上の絞り込みは **All / Active / Completed / Archived**。この絞り込みは URL に残らない — 開いているメニューを狭めているだけで、戻るボタンで戻ってくる「場所」ではないため。

## 3つの状態

- **ACTIVE** — 進行中。
- **COMPLETED** — 導出される。GOAL に入ってくるものが全部 DONE か CANCELLED になった時点で自動的にこうなる。人が選ぶものではない。
- **ARCHIVED** — 手で片づけたもの。Story settings の **Archive** から。読めるままだが、Active の一覧からは外れる。**Restore** で戻る。

## 直す・片づける・消す

ドロワーの行の **⋮ → Story settings…** から:

- タイトルと説明の編集（**Save**）
- **Archive** / **Restore**
- **Delete** — タスクも依存も一緒に消える。取り消せない。

今開いているストーリーを消したときだけ、行き先が必要になる。`/stories` が残っているストーリーの中へ送り返す。

## URL

- `/stories/<id>` — グラフ
- `/stories/<id>/list` — リスト
- `/stories/<id>/board` — ボード

どのビューもそのまま人に送れる URL になっている。
